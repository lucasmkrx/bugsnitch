# Security reporting

**Do not disclose exploitable vulnerabilities publicly in an issue or pull request.**

Use GitHub's private vulnerability reporting mechanism on the [repository Security page](https://github.com/lucasmkrx/bugsnitch/security), choosing **Report a vulnerability** when enabled. Private security advisories are the preferred channel. If the private reporting option is unavailable, ask a maintainer through an available GitHub contact mechanism to arrange a private channel, without publishing exploit details. No security email address is configured by this project.

Include the affected version, environment, impact, minimal reproduction, and any proposed mitigation. Avoid including credentials or proprietary repository contents. Coordinate public disclosure with maintainers so a fix can be prepared. No response-time SLA is promised.

The project is in early development. Reports against the current source or latest available development version are most useful; no long-term support release line is established yet.
