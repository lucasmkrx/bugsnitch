# Bugsnitch

One owner coordinates delivery across their repositories and registered computers. A project maps to one repository. The owner approves scope, selects issues, reviews evidence and answers versioned decisions. Planner, worker and manager are roles with separate contexts. Only eligible locally authorized execution may call a model.

The desired delivery chain runs from deliverable to canonical GitHub issue, isolated attempt, separately reviewed candidate, PR, integrated revision, deployment and environment verification. None of these implies the next step. An incident enters this chain after triage. Capture observations, preserve uncertainty, and require positive deployment-specific evidence for a production verdict.

The dashboard and ChatGPT tools share server records. User-selected local paths, execution credentials and local work stay under runner control. Single-owner workspaces are the initial release boundary. Teams, billing, native telemetry, deployment execution and marketplace distribution are outside this release. See PROGRESS.md for implemented behavior.
