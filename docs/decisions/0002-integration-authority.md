# 0002 · Integration authority and evidence

Default to explicit owner triage and GitHub App repository-scoped installation credentials. A durable outbox records promotion before the provider write. After ambiguous acceptance, search for the issue by private marker and App authorship; uncertainty blocks a second create. Preserve a closed or externally modified issue as observed.

Closing an issue or merging a PR alone does not establish deployment or user-visible correctness. Store deployment and validation receipts per build and environment. Automatic merging requires an enforceable current-base guarantee and all project policy gates. A PR head SHA on a REST merge request only fences the head.
