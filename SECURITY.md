# Security reporting

Report suspected vulnerabilities privately. Open the [repository's security advisories](https://github.com/lucasmkrx/bugsnitch/security/advisories) and choose **Report a vulnerability**. If you cannot access the form, contact a maintainer privately to arrange another channel.

Include the Bugsnitch commit or version, affected component, environment, impact and minimal reproduction. Use a disposable checkout and redact credentials and private repository contents. Coordinate public disclosure with the maintainers so they can prepare a fix.

The current developer preview is built from `main`. Reports against a recent commit are the most useful.
